# Role qualification execution v5 prevalidation

Status: frozen provider-locked pending a fresh class-scoped preflight.

V5 is the smallest correction to the halted v4 execution layer. It does not modify v1-v4 or their evidence. A claim is followed by a write-once attempt before transport entry. Each attempted cell must then have exactly one terminal artifact: either the existing immutable success receipt or a v5 transport-failure receipt bound to the attempt, claim, frozen request, and sealed preflight hashes.

Transport failure classification is typed by stage and cause. Error text is sealed evidence and cannot select failure scope. Only adapter-proven HTTP timeout, connection, and response-read failures are `invalid_unscored` with `observation_local_unscored`; they never eliminate the candidate or globally halt unrelated cells. Route, model, provider, turn, malformed/parsing evidence, credential, authentication, runtime, and configuration failures are exact typed global halts. HTTP status, content type, body or partial bytes and their hash, and any read error and its hash are preserved in the immutable failure receipt. There is no automatic retry. Provider-started failures with unavailable usage consume the complete frozen reservation conservatively while preserving separately reported unknown usage and the actual elapsed time when known. Pre-provider failures record zero calls and known zero provider usage.

The exact halted v4 claim and preflight are bound by SHA-256. The provider-free `recover-v4-stranded` command crash-safely copies or validates each already-written artifact in a new v5 evidence root, seals an unknown-settlement local-unscored receipt using the full reservation, and prohibits rerunning that cell. Recovery delay is not presented as provider wall time because the legacy timing is unknown. A generic provider-free reconciliation closes any durable attempt lacking either terminal receipt as ambiguous local invalid evidence with the full reservation and no retry. The v4 evidence root remains read-only and unchanged.

Provider execution remains disabled unless the exact v5 freeze validates and a fresh preflight for one exact configuration class is sealed. Each `execute-batch` invocation is still limited to that class's 12 counterbalanced cells, one attempt per cell, zero retries, zero fallbacks, and no external tools or production effects.

# Remaining role candidate artifacts v2

Status: **accepted provider-free artifact set; candidate-only; not wired or qualified**.

This directory completes the provider-free instruction/skill drafts for the
seven LLM-executed responsibility boundaries that survived the placement audit:

- Phone Farm Application Specialist;
- Phone Fleet Reliability;
- Data Sync & Integrity;
- Release & Runtime Reliability;
- Company Auditor;
- Architecture Assurance;
- Security & Privacy Review.

The four earlier candidates—Mika, Shared Windows Executor, Product/UI, and
Quality Checker—remain immutable in `../v1` and are not duplicated here.

Nine accountable-outcome identities remain controller-bound configuration and
domain-skill records, not conversational agent seats. Workflow movement,
authority, consequence linking, regression ownership, documentation truth,
notifications, backup, and recovery remain deterministic infrastructure.

`mac_alert_analysis.skill.md` is deliberately skill-only. It may explain a
sanitized non-critical watcher event when deterministic evidence is
insufficient. It creates no seat, cannot monitor or suppress alerts, and cannot
access a Mac. Phone Farm alerts stay inside the dedicated Mac roles.

These files define behavior to test. They grant no host, tool, repository,
credential, deployment, messaging, production, or Phone Farm authority and
select no model. Mechanical capabilities remain separate and fail closed.
They are intentionally not added to the live configuration-artifact resolver
at this stage. Older provisional model-labelled configuration decisions do not
activate these v2 files. Resolution must remain denied until the next gate
creates a separately versioned exact configuration binding without treating a
historical model label as a winner.

After this set is frozen or used in a trial, changes require a new versioned
directory and new hashes.

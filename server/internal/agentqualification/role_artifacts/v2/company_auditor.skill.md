# Company Auditor candidate skill v2

Use this sequence only for one named broad read-only audit:

1. Freeze the audit question, snapshot time, authorized scope, exclusions,
   definitions, populations, and requested deliverable.
2. Map each claim to an authorized read-only source and evidence freshness rule.
   Accept Phone Farm facts only through sanitized Mac-role receipts.
3. Reconcile named sources without mutating them. Record stale, missing,
   contradictory, and out-of-scope evidence explicitly.
4. Calculate every metric from a declared numerator and denominator; label
   direct observation, derived calculation, and inference separately.
5. Write findings before recommendations. Attach source, time, evidence lane,
   confidence, and limitations to each material conclusion.
6. Stop at the frozen audit boundary and emit only the twelve-field JSON response
   defined by the v2 instructions.

Quality checks before returning:

- Scope and snapshot time are explicit and unchanged.
- Important rates expose numerator, denominator, and definition.
- Absence of evidence is never treated as evidence of absence.
- Findings and recommendations cannot be confused.
- No implementation, provider action, issue verdict, monitoring promise, or
  Phone Farm operation is implied.

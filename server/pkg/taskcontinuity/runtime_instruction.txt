Before marking a goal or issue blocked, recover or route around the obstacle. A preferred tool, evidence source, shared checkout, or provider call failing is degraded execution: retry safely, use a supported fallback, create an isolated workspace, or continue other safe in-scope work. Browser access is mandatory for UI work. If one browser surface fails, repair it or switch among supported browser options until browser interaction works; source, API, logs, tests, screenshots, or agent claims do not replace browser-based UI verification. Browser recovery is agent-owned and does not become an owner decision by itself. Keep a waiting lane separate from the whole goal. Do not ask the owner to resolve agent inconvenience. Ask only for a consequential product/UI choice, security/trust/access change, destructive or production-data action, budget, outbound communication, scope expansion, or interruption not already authorized. Mark the whole goal blocked only when no safe action remains, recovery is exhausted, the same external condition has survived three unchanged checks, dated evidence names the accountable system or role, and the exact resume condition is known.

# Item 14 local documentation stewardship v1

- Status: accepted provider-free local gate
- Scope: Item 14 role, squad, instruction, skill, benchmark, transport,
  evidence, and current-continuation sources in this isolated checkout
- Production, provider, credential, model-selection, and permanent-seat
  authority: none

## Purpose

Item 14 accumulated several kinds of truth: frozen authority, executable
machine contracts, accepted test evidence, and mutable current status. This
gate prevents a later agent from silently reading one changed or stale layer
as if the complete set still agreed.

The manifest is
`server/internal/agentqualification/item14_stewardship_manifest_v1.json`.
The checker is `server/cmd/item14-stewardship-check`. The provider-free Item 14
acceptance target runs this local check in addition to the existing independent
Silver Mediums knowledge-hub stewardship check.

## Bound source classes

| Class | Meaning |
|---|---|
| `frozen_authority` | The accepted role-design decision register; it must not be rewritten to repair newer status language. |
| `machine_contract` | Graph, role catalog, locked cases, role-artifact manifests, role/squad contract and rehearsal, the closed primary-subscription trial gate and definition, its derived result, and the role-stage contract/rehearsal. |
| `accepted_evidence` | Architecture, responsibility, benchmark, topology, workflow, exact-model/provider boundaries, operating-contract records, the primary-subscription result, and explicit owner decision packets used to interpret the machine sources. |
| `current_status` | Current continuation, build progress, and append-only run journal. These may change, but every accepted change requires an explicit hash rebind and a fresh check. |

The source list is exact, canonical, and duplicate-free. Every path must remain
inside the repository, every SHA-256 must be valid, and every required source
must be present with its fixed evidence class and mutability designation.
Missing, extra, reordered, reclassified, path-traversing, or content-drifted
sources fail closed.

## Evidence boundary

This proves the current local Item 14 reading is internally replayable. It does
not say that the dirty checkout is committed, present in remote Git, deployed,
running in production, or business-accepted. It does not promote any model
label or role candidate. The existing 20-source Silver Mediums hub check
remains a separate authority surface and must also pass.

The check reads source bytes only. It does not read credentials, contact a
provider, run a model, access Phone Farm, make an outbound business action, or
change production state.

The current exact set contains 34 sources: one frozen authority, 13 machine
contracts, 17 accepted-evidence documents, and three mutable current-status
documents. The completed subscription trial and role-stage evidence remain
closed contracts; including them here records their definitions and terminal
results but grants no provider, credential, fixture, Browser, tool, model,
seat, or production authority.
